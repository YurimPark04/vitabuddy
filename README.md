# VitaBuddy (비타버디)

## 🏥 후기 중심 영양제 추천 및 구매 사이트
VitaBuddy는 사용자가 영양제의 성분, 부작용, 복용 방법 등을 쉽게 확인하고, 신뢰성 있는 후기를 바탕으로 자신에게 맞는 영양제를 선택할 수 있도록 돕는 웹 애플리케이션입니다.

---

## 🚀 프로젝트 개요
- **프로젝트명:** VitaBuddy (비타버디)
- **주제:** 후기 중심 영양제 추천 및 구매 사이트
- **목적:** 사용자가 필요로 하는 영양제를 검색하고, 필터링하여 구매할 수 있는 기능을 제공
- **주요 기능:** 영양제 검색, 후기 작성 및 공유, 사용자 맞춤 추천 기능 등

---

## 🎯 주요 기능
### 🔍 제품 검색 기능
- 기능별, 브랜드별, 성분별 카테고리 조회 가능
- 추천 순, 판매량 순 정렬 및 필터링 제공
- 드롭다운 형식의 검색 UI로 검색 시간 단축

### 📝 리뷰 기능
- 사용자가 제품에 대한 리뷰 작성 및 공유 가능
- 구매 영수증 및 제품 사진 업로드 기능 제공
- 제품 크기 및 포장 상태를 확인할 수 있는 시각적 정보 제공

### 💊 마이페이지 영양제 추천 기능
- 회원 정보 수정 및 복용 중인 영양제 입력 가능
- 건강 포털 데이터와 연동하여 복용 가능 여부 및 지도법 안내
- 영양제 간 상호작용 및 추천 영양제 기능 제공
